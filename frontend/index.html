01 / Problem Statement

The cost of fragmented campus records.

University administrators frequently rely on disconnected spreadsheets and paper files to track student admissions, departmental enrollments, and tuition balances. This creates administrative silos, delays financial reconciliation, and makes generating real-time institutional reports error-prone.

System Approach

Decoupled Client-Server Architecture (JSON REST API over PDO + Asynchronous Fetch UI).

02 / Problem Justification

Unified governance & zero-latency reporting.

By decoupling the presentation layer from a strictly normalized (3NF) MySQL database, administrative staff can securely authenticate, manage scholar lifecycles, and audit tuition arrears from a single workspace—eliminating redundant data entry and manual calculation errors.

Security Standard

Prepared PDO Statements, XSS Input Sanitization, and Role-Based Session Control.

03 / Engineering & Objectives

Designed with enterprise precision.

Relational Core

3NF Database Schema, Views & Triggers

Rather than flat tables, the backend separates Users, Departments, Courses, Students, and Fees with foreign-key integrity. Pre-computed SQL Views power the executive dashboard with zero PHP loop overhead.

Core Deliverables

Four Specific Objectives

  • I. Responsive Editorial Interface Bespoke CSS grid system with client-side validation.
  • II. Role-Based Session Security Dedicated access tiers for Super Admins and Finance Officers.
  • III. Modular PDO CRUD Engine Object-oriented PHP models consuming and returning pure JSON.
  • IV. Live Institutional Telemetry Three real-time reports across enrollment, departments, and fees.
